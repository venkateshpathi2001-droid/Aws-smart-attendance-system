# Aws-smart-attendance-system
 MSc Cloud Computing project exploring an AWS-based smart attendance system using serverless services and DynamoDB.
AWS Smart Attendance System

Overview

An MSc Cloud Computing project exploring a cloud-based student attendance and behaviour monitoring system using AWS services.

Project Goals

- Record student attendance events through an API.
- Store attendance records in DynamoDB.
- Process attendance events using AWS Lambda.
- Explore attendance anomalies and behaviour-score updates.
- Monitor application activity using AWS CloudWatch.

AWS Technologies

- Amazon API Gateway: Provides API endpoints for attendance and behaviour operations.
- AWS Lambda: Processes attendance events and updates records.
- Amazon DynamoDB: Stores attendance logs and student-related records.
- Amazon CloudWatch: Supports monitoring and troubleshooting.

Testing

The project used testing tools such as Postman to explore API requests and system behaviour.

Learning Outcomes

This project helped me develop practical understanding of serverless architecture, API integration, NoSQL data storage, and cloud application monitoring.
